# ts-gantt-engine Demo

A demo application showcasing the usage and capabilities of **ts-gantt-engine** —  
a highly customizable, lightweight Gantt chart engine built with **TypeScript** and rendered using **HTML Canvas**.

This project demonstrates real-world usage patterns, routing, dynamic data generation, task relations, and timeline controls.

## 📦 About ts-gantt-engine

**ts-gantt-engine** is designed for developers who need powerful Gantt chart functionality without heavy UI frameworks.

### Key Highlights
- Canvas-based rendering (high performance)
- Fully customizable timelines
- Parent–child task hierarchy
- Task dependency relations (FS, SS, FF, SF)
- Multiple timeline comparison (planned, original, updated, actual, etc.)
- Lightweight and framework-agnostic core

---

## ✨ Demo Features

This demo application includes:

- ✅ Interactive Gantt chart rendering
- 🔄 Random task data generator (stress testing)
- 📊 Multiple time scales: Day, Week, Month, Quarter, Year
- 🌲 Nested task hierarchy
- 🔗 Visual task dependencies
- 📚 Lazy-loaded documentation page
- 🌓 Responsive layout with isolated scrolling
